## Working With the Notebooks

Most learning materials are Jupyter notebooks. To work with them locally:

1. Install Python 3 and JupyterLab.
2. Clone this repository.
3. Create and activate a virtual environment.
4. Install the packages required by the notebook being studied.
5. Start JupyterLab from the repository root.
6. Open a notebook and run its cells in order.

Use the Python environment manager available on your system to create the environment, activate it, install JupyterLab, and start JupyterLab from the repository root.

Individual notebooks may require additional packages such as NumPy, pandas, Matplotlib, seaborn, scikit learn, SciPy, or TensorFlow. Review the imports in each notebook before running it.
